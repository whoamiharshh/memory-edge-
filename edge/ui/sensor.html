Phone as a vibration sensor

Put the phone flat on the running machine (e.g. a desk fan's base or a washing machine top). The phone's accelerometer (~60 Hz) streams to this device over HTTPS. It can see shaft-rate problems such as imbalance; it cannot see bearing defect frequencies.
